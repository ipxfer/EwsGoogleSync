Privacy Policy

EwsGoogleSync · Effective date: 2026-10-29

EwsGoogleSync is a personal script used only by its owner on the owner's own computer. This page explains what data it touches and what it does with it.

Data accessed

The app reads calendar event details from the owner's own work Exchange calendar: event title, start and end time, location, organizer and attendee names, and description. These details are written only to a calendar in the owner's own Google account.

Google user data

The app uses the Google Calendar API only to create, update and delete events in the owner's own Google Calendar. It does not read Google data for any other purpose. Google user data is not sold, shared, transferred to anyone, or used for advertising.

Storage

The Google OAuth tokens are stored encrypted with Windows DPAPI on the owner's PC only. There is no server, no cloud database, no analytics, and no third parties involved.

Retention and deletion

Access can be revoked at any time at https://myaccount.google.com/permissions. Deleting the synced calendar in Google Calendar removes all copied events. Once access is revoked, the stored tokens no longer work.

Limited Use

EwsGoogleSync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
